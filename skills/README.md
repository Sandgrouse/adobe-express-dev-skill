# Skills Index

This directory contains the modular Adobe Express composite skill set.

## Skills

- adobe-express-core: architecture, runtime boundaries, MCP routing, installation strategy.
- adobe-express-spectrum-ui-ux: Spectrum UI and UX patterns.
- adobe-express-document-manipulation: document sandbox and content operation planning.
- adobe-express-oauth-authentication: OAuth, PKCE, token lifecycle.
- adobe-express-monetization: checkout, webhook, entitlement architecture.

Use the top-level README for installation and host setup.
